# Kanak Prabhakar VS Code Extension Ecosystem

Integrated suite of developer extensions for Visual Studio Code providing visual architecture graphing, AST analysis, and systems debugging.

## Architecture
- `packages/`: Modular extension sub-packages.
- `MASTER_GRAPH.md`: Comprehensive graph dependency specification.
- `PRODUCTION_VALIDATION_REPORT.md`: Audit and validation certification.

## Prerequisites
- Node.js 18+, VS Code engine ^1.80.0

## Build & Test
```bash
npm install
npm run build
npm test
```
